

# 1️⃣ Define the **application scope**

**Optimal**: academic documentation platform for students and professors.
Main features:

1. **Course** management (Markdown → HTML rendering)
2. Navigation (sidebar, breadcrumbs, table of contents, scrollspy)
3. Theme (dark / light)
4. Search and consultation
5. User management (optional for later)

---

# 2️⃣ Identify the **main entities**

### Main entities (UML classes)

| Class                 | Responsibilities                     |
| --------------------- | ------------------------------------ |
| **Course**            | title, description, list of sections |
| **Section**           | id, Markdown content, title, level   |
| **User** (optional)   | student / professor, preferences     |
| **MarkdownService**   | parse Markdown to HTML, generate IDs |
| **ScrollSpyService**  | observe sections, activate nav       |
| **ThemeService**      | manage dark / light mode             |
| **CourseService**     | manage courses (CRUD / loading)      |
| **BreadcrumbService** | compute paths / navigation           |

# 3️⃣ Conceptual UML **Class Diagram**

```
+-----------------+
|      Course      |
+-----------------+
| - id: string     |
| - title: string  |
| - sections: Section[] |
+-----------------+
| + getSection(id) |
+-----------------+

        1
Course ------- * Section
                  +----------------+
                  |   Section      |
                  +----------------+
                  | - id: string   |
                  | - title: string|
                  | - content: string |
                  +----------------+
                  | + render(): HTML |
                  +----------------+

+------------------------+    +-------------------+
|   MarkdownService      |    | ScrollSpyService  |
+------------------------+    +-------------------+
| + parse(markdown): HTML |    | + observe(ids)   |
| + getHeadings(html)    |    | + activeId(): string |
+------------------------+    +-------------------+

+----------------+
| ThemeService   |
+----------------+
| + toggleTheme()|
| + getTheme()   |
+----------------+
```

💡 Notes:

* `Course` contains multiple `Section`s
* `MarkdownService` transforms the content of each section
* `ScrollSpyService` observes the IDs generated by `MarkdownService` to activate the TOC / sidebar
* `ThemeService` manages the dark / light mode state

# 5️⃣ UML **Component / Angular Architecture**

```
AppComponent
|
+-- HeaderComponent  (Theme toggle, breadcrumbs)
|
+-- SidebarComponent (Course navigation, TOC)
|
+-- CourseDetailComponent
     |
     +-- SectionComponent (renders Markdown)
```

Injected Services:

* MarkdownService → CourseDetailComponent / SectionComponent
* ScrollSpyService → Sidebar / TOC
* ThemeService → HeaderComponent / AppComponent
* CourseService → CourseDetailComponent / SidebarComponent
